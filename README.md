# Cita Rasa Peninggalan — Katalog UMKM Kuliner Khas Solo

A single-page, responsive catalogue of traditional food small businesses (UMKM) from Surakarta (Solo). The look is Javanese heritage (sogan brown, parchment cream, muted gold, olive) with app-like interactions: entrance animations, card hover and press feedback, and a detail dialog that opens without leaving the page.

The site itself is in Bahasa Indonesia (`<html lang="id">`).

> **All business data is demo data.** Business names, addresses and origin stories are examples. Every address is fictional and labelled as such in the UI. See [Before going public](#before-going-public).

## Tech stack

| Area | Choice |
| --- | --- |
| Framework | [Next.js](https://nextjs.org) 16 (App Router, Turbopack, Cache Components) + React 19 + TypeScript |
| Styling | [Tailwind CSS](https://tailwindcss.com) v4 (CSS-first config in `src/app/globals.css`) |
| UI components | [shadcn/ui](https://ui.shadcn.com) on [Radix UI](https://www.radix-ui.com): card, dialog, button, scroll-area, badge, separator, aspect-ratio |
| Animation | [Motion](https://motion.dev) (`motion/react`) for the hero entrance and gallery reveal only |
| Icons | [lucide-react](https://lucide.dev) |
| Fonts | Playfair Display + Inter, self-hosted via `@fontsource-variable` |

## Getting started

Requirements: Node.js 20.9 or newer (developed on Node 24 LTS) and npm.

## Editing the catalogue

All entries live in [`src/data/umkm.ts`](src/data/umkm.ts):

```ts
type Umkm = {
  id: string;
  nama_makanan: string;
  nama_umkm: string;
  deskripsi_singkat: string;   // shown on the card (clamped to 2 lines)
  deskripsi_lengkap: string;   // shown in the dialog under "Kisah & Cita Rasa"
  alamat: string;              // fictional in this build
  url_gambar: string | null;   // null → styled fallback is shown
  alt_gambar: string;
  is_demo: true;
};
```

Images that are missing (`null`) or fail to load fall back to a cream panel with an ornament and the food name, so a broken-image icon never appears.

## Design notes

- **Colours** are shadcn theme variables in `globals.css`. Muted gold (`#B08D57`) is only for borders, ornaments and icons, never text (it fails WCAG AA contrast on cream).
- **Animation split:** Tailwind handles hover, press and focus transitions. Motion handles only the hero entrance and the gallery reveal. The dialog uses shadcn's built-in open/close animation.
- **Reduced motion:** with `prefers-reduced-motion: reduce`, slides, stagger, image zoom and smooth scrolling are turned off.
- **Accessibility:** each card is one real `<button>` labelled "Lihat detail …". The dialog closes with Esc, the close button or an overlay click, and focus returns to the card that opened it. The CTA moves focus to the gallery heading.

## Changes from the spec

The build spec (`docs/MASTER_PROMPT.pdf`) asks for Vite. This project uses **Next.js** instead, at the project owner's request. Resulting differences:

- Global styles are in `src/app/globals.css` instead of `src/index.css`.
- The favicon is `src/app/icon.svg` (Next.js file convention) instead of `public/favicon.svg`.
- Images use `next/image` with `unoptimized`, so they load straight from Unsplash with no image proxy.
- Cache Components does not allow `new Date()` while prerendering, so the footer year comes from a cached function that refreshes daily.

## Out of scope

No backend, database, CMS, auth, search or filter, cart, maps embed, language toggle, dark mode or analytics.

## Before going public

- Replace the demo images with real, licensed photos of each dish. The current Unsplash URLs are unverified and may not show the named dish.
- For any real business shown, get its permission and use its real, verified details. Otherwise rename it.
- Have a local source review the origin stories. They are popular narratives, not verified history.
